WebTransport echo conformance

Proves a real browser's built-in WebTransport against the Go reference echo server in server/: a 64 KiB bidirectional stream transfer that must come back byte-identical, a datagram round trip, and a unidirectional stream the server echoes on a stream of its own. This is transport conformance only — no application protocol, no authentication, no gameplay.

Start the server and serve this page from an origin it allows:

go -C server build -o tn-network-server .
./server/tn-network-server --listen 127.0.0.1:4433 --dev-self-signed \
  --allow-origin http://127.0.0.1:8000
python3 -m http.server 8000 --bind 127.0.0.1   # then open http://127.0.0.1:8000/client.html

The server prints one CERT_SHA256 <base64> line for its development certificate. Paste it below: a self-signed certificate is only reachable from a browser by pinning that digest through serverCertificateHashes. Running from file:// will not work, and neither will an origin missing from --allow-origin.
