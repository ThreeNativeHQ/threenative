# PRD-359 tasks 7wait-a/b — bounded resource waits — 2026-09-06

The playtest runner now has one validated `waitForResource` step. It requires a positive integer
`timeoutMs` no greater than 120000 and exactly one of `equals`, `gte`, or `lte`; input, tick and
other action fields are rejected. The runner includes wait resource ids in every bridge sample,
fails immediately when the observer or path is absent, and reports the predicate, elapsed time and
last value when a real wall-clock deadline expires.

The shared helper yields for at most 16 ms between observations. Browser fixed-step bridges advance
at most one tick after each real interval; native Android, desktop and iOS use the same native
runner path and existing resource bridge. No CDP or fixed-tick substitution is used for the
deadline.
