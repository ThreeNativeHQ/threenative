# PRD-248 verification — atmosphere LUTs and game-owned sky

**State: PARTIAL.** Web implementation and consumer evidence completed on 2026-08-28. The
physical Android and Pixel 8 lanes were not executable because `adb devices` returned only
`List of devices attached`.

## Delivered

- Added game-supplied atmosphere parameters, solar-position helpers, transmittance/multi-scattering/
  sky-view LUT compute nodes, and lifecycle/disposal through the `IComputeDriven` shape.
- Added `Atmosphere.radiance()`, `sunTransmittance()`, and the depth-based
  `aerialPerspective()` seam. The class creates no mesh, material, light, preset, or physical
  default.
- Added the minimal template's game-owned sky mesh/material, sun light, solar-day update, depth
  probe, composite line, and atmosphere playtest.
- Kept the ordinary scene render order and renderer path unchanged when no depth-coupled object is
  added; the focused game test covers both branches.
