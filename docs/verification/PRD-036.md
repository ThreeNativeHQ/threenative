## Manual replay checkpoint

The real `examples/abyss-framework` subject was run on the same isolated Brave/WebGPU/X11
runner. A held-Enter start plus four held movement directions produced a 50-tick recording
with 7 input samples. Calling the dev replay hook rebuilt the scene and replayed those exact
ticks; the observed player position matched byte-for-byte at the reported precision:

```text
live:   [5.764744350219415, 25.916799661339002, 0]
replay: [5.764744350219415, 25.916799661339002, 0]
maxDelta: 0
score: 0 -> 0
consoleErrors: 0
```

This checkpoint required two consumer fixes: the Abyss scene now draws simulation randomness
from `ctx.random`, and the dev replay hook restores the recording's RNG state before
`game.goto("play")`.

## 1% divergence checkpoint

The Abyss subject has no jump action; its equivalent input impulse is the horizontal movement
coefficient (`560 * dt`). A disposable browser variant changed only that coefficient to
`560 * 1.01`, accepted the same recording through `createReplayDriver`, and was removed after
the run.

The browser recording used the same DOM `InputMap` path for 90 fixed ticks: Enter start,
ArrowRight for 60 ticks, then release. It contained four input samples at ticks 6, 18, 24,
and 84.
