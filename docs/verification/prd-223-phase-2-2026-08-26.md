## First native execution and triage

The first real run discovered 21 targets from `CMakeLists.txt`, reported every target, and ended
with 18 PASS / 3 FAIL:

```text
threenative-physics-actuation-bindings-test: undefined reference to initializeNativePhysicsBindings
threenative-video-recorder-state-test: verification build lacked Ninja/compiler paths
threenative-webgpu-bindings-reentrancy-test: command encoder or pass state was not restored
```

- Physics was rotted lane wiring, not a runtime defect. The shipping preset correctly disables
  native physics, so the proof now uses a dedicated physics-enabled verification build and the
  host Rust archive.
- Video was rotted lane wiring. The shipping preset remains video-disabled; the proof now uses a
  dedicated video-enabled verification build with tool paths inherited from the shipping cache.
- WebGPU was a product regression in the cached `GPUCommandEncoder` prototype fast path. A pending
  JS exception could bypass transactional rollback. The fast path now rejects pending exceptions;
  the fresh native reentrancy proof is green.
