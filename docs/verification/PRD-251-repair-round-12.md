## Repair

`validateBridgeTriangleTopology` now requires a present, well-formed position attribute and index,
the exact two-sided-strip index count, the exact connectivity generated by `stitchGeometryData`,
and a zero-start, complete, triangle-aligned draw range. It also checks bridge position coordinates
before an existing bridge can be refreshed. Missing, empty, partial, non-triangular, degenerate,
disconnected, duplicated, out-of-range, or otherwise malformed bridge data throws the existing
bridge-topology diagnostic. Existing finite-coordinate and X/Y/Z endpoint checks remain intact.
