and a 19-line WebGPU `RenderPipeline` wrapper. Focused scaffold look tests cover
those source contracts.

## Browser evidence

Command:

```text
pnpm test:browser
```

The playtest CLI built and passed publint. The starter-look gate passed with a
1280x720 screenshot containing the named warm crate, cool player, and a dark contact
shadow region. The measured frame cost was:

```text
starter-look frame cost: 96.104 ms/frame over 120 frames
```

The starter runner deliberately omits `--enable-unsafe-webgpu`; Three.js reports
`WebGPU is not available, running under WebGL2 backend.` The framework remains
WebGPU-first, and `setupPost` uses `RenderPipeline` when the WebGPU renderer is
actually active.

Negative controls were observed red and then restored:

- `renderer.shadowMap.enabled = false` → `Starter look reference failed:
  contact-shadow coverage 0.0000 is too low.`
- Replacing the crate palette with the floor palette → `Starter look reference failed:
  warm crate pixels 0 are missing.`

The gate remains fail-closed: a black frame, missing palette region, missing contact
shadow, or captured browser error fails the consumer run.
