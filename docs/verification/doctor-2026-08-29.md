# PRD-264 doctor evidence — 2026-08-29

This record covers the four doctor probes in PRD-264. The doctor was run read-only: it did not
install packages, write project files, or run a build. The sandbox comparison below uses the
installed CLI for the before run and this lane's rebuilt CLI for the after run.

## Red before the implementation

The new doctor cases were added before their implementation. The pre-fix focused run was red:

```console
$ pnpm exec vitest run packages/create-threenative/__tests__/doctor.spec.ts
Test Files  1 failed (1)
Tests  9 failed (33)
```

The failures covered the absent engine package, three per-server MCP results, malformed MCP
configuration, mobile asset settings, an unwritable asset path, the missing and delegated
playtest runner, the unsupported Android JDK, and the Craft/Test/Ship grouping. The existing
no-runtime-dependency assertion was already green and stayed green.

## Phase 1 — capability search

The post-fix run reports each server independently and distinguishes an absent package from a
malformed configuration:

```console
$ pnpm exec vitest run packages/create-threenative/__tests__/doctor.spec.ts -t "capability search|MCP servers|malformed capability"
Test Files  1 passed (1)
Tests  4 passed | 31 skipped (35)
```

The in-memory negative control with a valid generated `.mcp.json` and no installed
`threenative-engine-mcp` reports `warn` and names `threenative-engine-mcp@0.2.0` with its npx
fallback. The malformed-config control reports `fail` and names invalid JSON.

## Phase 2 — asset pipeline

Before the doctor change, the mobile asset and unwritable-directory cases were among the nine
failing tests above. After the change:

```console
$ pnpm exec vitest run packages/create-threenative/__tests__/doctor.spec.ts -t "compiled assets|asset path"

Tests  2 passed | 33 skipped (35)
```

The matching native build refusal was also observed directly:


## Phase 3 — playtest delegation

The pre-fix missing-runner and delegated-runner cases were red in the nine-test run. The post-fix
cases are green, and the package manifest still has no runtime playtest dependency:

```console
$ pnpm exec vitest run packages/create-threenative/__tests__/doctor.spec.ts -t "playtest runner|delegated playtest|runtime dependency"
Test Files  1 passed (1)
Tests  3 passed | 32 skipped (35)
```

An absent `node_modules/.bin/threenative-playtest` is reported as a named failure with
`npm install -D @threenative/playtest`. When present, the runner's `doctor --text` output is
folded under the `playtest` check; nonzero output preserves both stdout and stderr.
