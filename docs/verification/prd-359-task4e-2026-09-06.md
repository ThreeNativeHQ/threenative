# PRD-359 task 4e evidence

Date: 2026-09-06
Branch: `networking-359`

## Scope

Task 4e owns the standalone runtime credential issuer, per-client grant staging,
and the existing native verified-certificate fixture's authenticated `/game`
caller. The issuer stages only `{issuerAuthorization,expiresAt}` beside the
client assets, validates the grant and browser origin, calls the loopback Go
issuer for a fresh join credential, and removes its staged file during cleanup.

## Red / diagnosis

The first live authenticated join reached the Go server but failed before the
first reliable BIND:

```text
FAIL: Stream reset (code 91141958510811)
game server stderr=... game: handshake rejected: accepting the channel 3 stream: H3_DATAGRAM_ERROR (local): Application error 0x0 (remote)
```

The cause was in the reference server's `ServeGame`: its pre-HELLO extra-stream
watcher remained active after HELLO and could consume the first post-WELCOME
BIND stream. The repair gives both probe goroutines a cancelable context and
joins them before WELCOME/BIND processing.
