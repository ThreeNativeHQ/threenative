# PRD-043 verification — terrain and open worlds

Date: 2026-08-08

State: in progress. Phases 0–3 are implemented and evidenced; the repository-wide gate
result is recorded below before the PRD is moved to `docs/PRDs/done/`.

## Delivered

- `CollisionShape3D.heightfield` validates integer dimensions and the exact
  `rows * columns` height buffer before creating Rapier's `rows - 1` by `columns - 1`
  heightfield.
- `AssetLoader.release(kind, path)` evicts one resolved cache entry and reports whether it
  existed.
- `visibility.present` is a fail-closed playtest assertion for registered streamed
  entities; runtime observations also expose entity visibility.
- `examples/abyss-framework/src/scenes/TerrainProbe.ts` streams three terrain chunks,
  creates a heightfield collider per chunk, releases model cache entries on unload, and
  is selected by `?terrain` without changing the frozen default example path.
