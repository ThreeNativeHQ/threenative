# PRD-046 verification evidence

Date: 2026-08-08
Status: Phase 0 complete; Phases 1–5 open

## Phase 0 — Rapier version divergence

The repeatable measurement command passed:

```text
pnpm --filter @threenative/runtime-native native:physics:measure
```

It ran PRD-036's exact contact-rich subject on both arms: seed 1, a five-box stack on a
floor, 300 fixed ticks at 1/60. The web arm used `World.takeSnapshot()` from
`@dimforge/rapier3d-compat` 0.19.3. The native arm used `rapier3d` 0.30.0 and serialized the
same nine fields in the same order as Rapier.js 0.19.3's `SerializableWorld`.

| Measurement | Web 0.19.3 | Native 0.30.0 | Delta |
|---|---:|---:|---:|
| Snapshot length | 9,757 bytes | 9,757 bytes | 0 bytes |
| Byte values | — | — | **62 bytes differ** |
| Maximum final-position delta, five bodies × three axes | — | — | **0** (bit-identical `f32`) |

The final body positions were bit-identical even though 62 serialized solver-state bytes
differed. This is the bounded result PRD-046 required: the version change is not described
as portable replay, and the byte mismatch is not hidden by equal visible positions.

## Android cross-compile proof

```text
pnpm --filter @threenative/runtime-native native:physics:cross
aarch64-linux-android: libthreenative_native_physics.a 11080132 bytes
x86_64-linux-android: libthreenative_native_physics.a 11255828 bytes
```

Both release static libraries compiled with Rust 1.96.0 and Android NDK 27.1.12297006
(Clang 18.0.2). Outputs live under ignored `packages/runtime-native/.runtime/`; no binary or
downloaded dependency is tracked.

## Spike unit controls

```text
cargo test --manifest-path packages/runtime-native/native/physics/Cargo.toml
3 passed; 0 failed
```

The controls prove the narrow floor/cube spike rests at the expected height, falls through
when collision masks exclude the pair, and rises under deliberately inverted gravity.
They do **not** prove the C ABI, QuickJS binding, Android runtime integration, device
scenario, backend selection in `@threenative/physics`, iOS, arm64 execution, or performance.
Those remain open.
