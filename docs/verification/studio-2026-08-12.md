## Post-review defects, found and fixed 2026-08-12

Studio was re-inspected after the fact by starting the built server against
`examples/abyss-framework` and driving the browser with Playwright under
`xvfb-run -a -s '-screen 0 1600x1200x24'`. The game rendered inside the preview iframe
(`canvas 1122×765`) and every observed-state control behaved as the table above describes.
Four defects the original run did not cover were found and fixed.

1. **Checkpoint committed the whole repository.** `git add -A` run from a subdirectory stages
   the entire work tree, so a project nested in a larger repository was checkpointed together
   with every unrelated change, while `git restore … .` only ever restored the project
   directory. Observing, staging, committing and listing history are now all scoped with
   `-- .`, which makes the four agree. Proved by a new test: a sibling directory's edit leaves
   `dirty` false and survives a checkpoint uncommitted.
2. **The browser polled twice.** `refresh(); setInterval(refresh, 1500)` appeared twice in the
   client, so every tick ran two status requests and six `git` subprocesses. Measured 8 API
   requests per 6-second window before the fix and 4 after. A test now asserts one schedule.
3. **A failed status response froze the panel.** `refresh()` assigned any response body,
   including a `500` error object, so `render()` threw on `status.agent` and the UI kept
   displaying its last state indefinitely. It now accepts only a well-formed body and
   otherwise falls back to an explicit unavailable state.
4. **Interrupting Studio orphaned the preview.** `close()` did stop `pnpm dev`, but the CLI
   installed no signal handler, so a signalled Studio left the dev server holding the preview
   port — and `--strictPort` then made the next start fail. `SIGINT` and `SIGTERM` now close.

The layout was also corrected: at 1600×1200 the evidence and ownership dock fell below the
fold because the shell asked for `100vh` plus a `calc(100vh - 148px)` workspace. The shell is
now a flex column and the preview frame absorbs the remaining height.

**The `claude` agent path was executed for the first time here.** `detectAgent` prefers it
when no `--agent` is given, but only `codex` had been run. `runAgent` with the shipped
`claude` argument vector edited exactly the requested constant in a temporary project, exit
`0` in `10.907` seconds.

Gates after the fixes: `pnpm typecheck`, `pnpm lint` (179 pre-existing warnings, no errors),
`pnpm test` (101 files, 848 tests) and `pnpm budgets` (9,544/15,000 framework LOC; the
pre-existing native-runtime trigger is unchanged).

## Streaming, and the reference-shaped surface — 2026-08-12

The first Studio browser buffered the whole agent run: an instruction produced one transcript
entry up to two minutes later, so the panel looked inert while Codex was working. It also
had no place to show what the agent did. Both are fixed, and the surface was rebuilt to the
structure of the sibling project's Studio reference — slim top bar, chat rail, large preview,
and one hideable dock — with ThreeNative's own evidence in the panels.

- **The agent streams.** `codex exec` now runs with `--json` and `POST /api/chat` answers as
  Server-Sent Events. `agentStep` maps one stdout line to a step and returns nothing for
  lines that carry no progress; unit tests pin the command, file-change, message and
  ignored-line cases. Observed live: the first step reached the browser 5 seconds after send
  and 6 steps streamed before the turn completed in 20 seconds, exit `0`.
- **The agent timeout was wrong.** 120 seconds killed real work mid-edit. It is now 15
  minutes for the agent and 5 for the playtest runner.
- **Changed files are reported, not inferred.** A turn ends with the paths `git status`
  shows for the project, listed under the turn and counted in the activity column.
- **The dock hides**, remembering the choice in `localStorage`; the preview takes the height
  back — measured 668px with the dock open and 912px closed at a 1600×1000 viewport. The top
  bar is one 48px row.
- **The console column is the dev server's real output**, captured from the preview process
  and stripped of terminal colouring — not a claim about the game's own console, which is
  cross-origin and therefore unreadable. No FPS counter is shown for the same reason.
- **Game and Code views**: Code reads `git diff` for the project, so the source the agent
  edited is inspectable without leaving the page.

Gates: `pnpm typecheck`, `pnpm lint` (181 warn-level diagnostics, no errors), `pnpm test`
(101 files, 850 tests, exit `0`) and `pnpm budgets` (10,216/15,000 framework LOC). Three
`scripts/` LOC tests failed once against a dirty example during this work and passed on the
restored tree — the example edit was scratch, not part of this change.
