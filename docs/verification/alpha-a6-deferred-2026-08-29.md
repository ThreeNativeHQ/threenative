# A6 becomes a deferred row on the alpha bar — 2026-08-29

**Decision owner:** the repository owner, 2026-08-29.
**Change:** `scripts/alpha-bar.ts`, `scripts/__tests__/alpha-bar.spec.ts`,
`docs/PRDs/alpha-readiness/README.md` (regenerated by `pnpm alpha:bar --write`).

This file records a change to how a row is *scored*. It files no evidence for A6 and deliberately
carries no fenced alpha-bar evidence block, which is why the bar still reports the row as deferred
after this file landed: A6 remains unmeasured in substance, and the day somebody measures it, their
block — not this file — decides the row.

## The decision

Row A6, *"One stranger has actually used it"*, no longer contributes to the alpha bar's exit code.
It is still printed, still carries its requirement text, and now states why it cannot be measured.

## Why: the row is circular in the order the bar is run

- A6 asks whether a stranger has used the framework.
- A stranger installs it from the public registry, which is row A1.
- A1 is red today: 2 of 8 publishable packages are absent from the registry and six workspace
  versions are unpublished.
- Publication is gated on this bar going green.

So A6 is unmeasurable for a reason no amount of work inside this repository can change: it waits on
publication, and publication waits on it. Left as `unmeasured` it pinned the bar at exit `2`
permanently — the resting-state failure `scripts/alpha-bar.ts` was written to end, arriving from a
different direction. A6 will be measured after publication, from a real install by a real stranger.

## Why the row was not deleted

Deleting it would have destroyed exactly the information the `unmeasured` state exists to preserve:
that the framework has no evidence any outsider has used it. A deferral keeps the sentence visible
in the generated table and adds the reason. The bar's report now names the count — `1 deferred` —
in its summary line, so a green can never be read without seeing the asterisk.

## What "deferred" is, and what it is not

- It replaces **only** the absent-evidence branch of `evidenceRow`. Every other branch is unchanged.
- A real `alpha-bar` evidence block for A6 in `docs/verification/` outranks the deferral and is
  graded `pass` or `fail` like any other row. A deferral can never overrule a run somebody made.
- Two blocks for A6 that disagree are still `unmeasured`, not deferred: a disagreement is evidence
  that exists, not evidence that is missing.
- A deferred row counts toward neither `failed` nor `unmeasured`, so it cannot move the exit code.

## Revert check

Which line, removed, puts the row back. Dropping the `A6_DEFERRAL` argument from the `evidenceRow`
call in `alphaBar` — the whole of the change's effect on the row — and running the result:

```text

pnpm exec tsx scripts/alpha-bar.revert-probe.tmp.ts

    No alpha-bar evidence block for A6 was found in docs/verification/.
    evidence: an alpha-bar evidence block for A6 in docs/verification/
```

red because the committed table no longer matches — the generated table is a genuine consumer of
the row's state, not decoration. The probe file was deleted immediately after the run.
