## Route-follower decision and integration acceptance

PRD-090's predecessor evidence records `Driveline.ts` at 95 lines, above the 20-line promotion
threshold. This repair keeps `PathFollow3D` in `@threenative/core` for generic following,
projection, point sampling, and route distance. Lap-aware progress and place ordering now live in
the racing template's `src/track/Ranking.ts`; core does not own racing vocabulary.

The three original route sites are accounted for explicitly:

| Original site | Evidence in this lane | Closure state |
|---|---|---|
| Racing `packages/create-threenative/templates/racing/src/track/Driveline.ts` | The staged PRD-090 source is deleted; `Track.ts`, `Rival.ts`, `TrackSector.ts`, and `Race.ts` now use `@threenative/core:PathFollow3D`; `Ranking.ts` owns lap/place ordering; `racing.spec.ts` executes it | **closed** — direct source inspection and the six WebGPU scenarios prove the rewrite; the manifest is historical inventory, not closure evidence |
| Strategy `templates/defense/src/attackers/Attacker.ts` | imports and constructs `PathFollow3D` | **closed** — the promoted core follower is the route implementation |
| Platformer `templates/platformer/src/entities/Chaser.ts` | imports and constructs `PathFollow3D`; executable reach-gating proof below | **closed** — the promoted core follower remains the route implementation |

The racing source was present as staged input at the start of this lane. The source file is now
actually deleted, all racing imports/references are rewritten, and the replacement is exercised by
the local ranking test plus real WebGPU scenarios. The checked-in route-closure manifest remains a
historical source inventory; no gate treats it as proof of deletion.

## Implemented proof

- `templates/defense/` contains `kit.json`, a portable `src/game.ts`, a React-only `src/main.ts`,
  render source, authored route following, spatial-query placement and targeting, waves, economy,
  HUD state, and four playtest scenarios.
- `src/` is scanned for `@threenative/physics/navigation` and the rejected fog-of-war, marquee,
  navmesh, tech-tree, and navigation-node vocabulary.
- Route and tower queries use bounded `directSpaceState.intersectShape` calls.
- The platformer chaser advances its promoted route only after reaching the current sampled point;
  an executable regression proves both the not-reached and reached cases, and the focused
  path-follower malformed-route/delta negative control remains in core coverage.
- The native geometry HUD uses a camera-space depth of `-1.5` and `0.009` glyph scale, with numeric
  win/loss frustum assertions; toon cache entries include both color and roughness.
- The 300-frame scan window requires 16–28 scans for the seeded jitter clock.
- Twenty attackers are scheduled across ten waves, making both the ten-wave win and twenty-leak
  loss conditions observable.
