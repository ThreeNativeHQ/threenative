## Rejected with evidence (one row)

**Replay viewport cache.** Caching `getBoundingClientRect()` across ticks failed
`should record pointer coordinates relative to the canvas`: a canvas can move or resize between
recordings with no observable signal a cache could key on, and a stale offset silently corrupts
recorded pointer coordinates. The read stays; only the per-tick string joins (`join()`
comparisons for pointer tuples and key lists) became field comparisons. The failing cache was
reverted in the same session — recorded so it is not re-proposed.
