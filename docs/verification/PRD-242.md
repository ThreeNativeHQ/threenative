## Contract and consumer proof

- IComputeDriven is exported from @threenative/core with @situation and @example documentation.
  ComputeDrivenRegistry records scene-add order, attaches the active renderer, dispatches once per
  fixed step, releases detached objects, and clears all objects on scene changes and teardown.
- GPUParticles3D implements the contract through the same registry. The pre-existing
  packages/core/__tests__/particles.spec.ts remains unchanged and passes.
- warmUpScene accepts compute nodes, calls the renderer's compute warmup seam before draw
  compilation, shares the existing bounded startup budget, and reports compiled, abandoned,
  unsupported, and timed-out compute work.
- examples/prd242-compute-lifetime/src/ping-pong-field.ts is a non-particle IComputeDriven object
  with two ordered passes and two ping-pong storage buffers. The game adds it through ctx.add,
  changes scenes twice, and observes release/rebuild counters through the playtest bridge.
