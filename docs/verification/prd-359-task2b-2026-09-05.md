## Runtime wiring

`src/runtime-scripts/webtransport-polyfill.js:452` calls native `__wtStreamWrite` with
whole-write admission, retains bounded copied input while status -2 waits for a
capacity event, and observes controller abort signals for both writes and pending
FIN completion. `__wtStreamShutdown` selects read or write independently.

`src/webtransport/webtransport.cpp:780` consumes payload only with read credit. Credit
refresh subtracts bytes already queued in native events. Reads resume on idle
socket ticks. Header parsing reads exact varint boundaries and validates the
CONNECT session before announcing a stream or consuming payload. The native read
pass bounds bytes, calls and stream selection, rotating progress across streams.

Native limits are 64 tracked streams, 16 KiB read credit per stream, 256 KiB and
256 receive calls per session tick, and 64 UDP receives per tick. QUIC receive
windows are bounded to 1 MiB per connection and 64 KiB per stream. The previously
accepted native reliable send queue remains capped at 1 MiB. JS reliable admission
is capped at 1 MiB and 256 operations, including zero-byte writes; datagram queues
are capped at 256 operations/items. These are queue bounds, not RSS qualification.

Completed readable streams retain native ownership until buffered data drains.
Canceling an incoming acceptance queue disposes unaccepted streams, including both
halves of a discarded bidirectional stream, while preserving accepted streams.
Local transport close settles outstanding operations and releases retained queues.
`src/runtime-scripts/webtransport-polyfill.js:904` (`__wtResourceStats`) reads actual native counters plus tracked JS state; missing
native observations throw instead of being replaced with zero.
