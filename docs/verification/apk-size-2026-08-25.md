## Reconciliation to the 2026-08-24 probe

The probe recorded **379,285,298 bytes** for
`sandbox/fps-framework/dist-native/fps-framework.apk`. That exact artifact is
no longer present. The current read-only sandbox APK is a later
**443,302,546-byte** artifact, and its observed `lib/x86_64/libmystral-runtime.so`
entry is **64,015,208 bytes**. Subtracting that entry gives:

```text
443,302,546 - 64,015,208 = 379,287,338 bytes
379,287,338 - 379,285,298 = 2,040 bytes
2,040 / 379,285,298 × 100 = 0.00054% (rounded)
```

This 0.00054% residual is archive/source metadata drift; it is not a
byte-for-byte reproduction of the absent historical APK. The clean fixed
rebuild is a separate artifact:

```text
173,572,580 - 379,285,298 = -205,712,718 bytes
```

The controlled comparison below isolates the packaging change on the current
inputs. It does not claim that the clean fixed build reproduces the historical
probe.

## Negative control: restore the old packaging setting

The old `jniLibs.keepDebugSymbols.add("**/*.so")` setting was restored
temporarily, then the same clean Android package was rebuilt from the same
inputs. The observed totals were:

| Build | APK bytes | Entry bytes | ZIP overhead |
| --- | ---: | ---: | ---: |
| Old setting (`control.apk`) | 297,403,456 | 279,877,975 | 17,525,481 |
| Fixed setting (`app-debug.apk`) | 173,572,580 | 173,525,455 | 47,125 |
| **Fixed − old** | **−123,830,876** | **−106,352,520** | **−17,478,356** |

The control rebuild restored the pre-fix byte total for the controlled input
set, and the source was restored to the fixed setting before the final clean
rebuild. V8 entries were unchanged; SDL3 and `libmystral-runtime.so` account
for the native-library reduction. The large ZIP-overhead difference is also
part of the observed old packaging output and is included in the total delta.
