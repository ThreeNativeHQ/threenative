## Review repairs

The read-only Linchpin review found four defects in the first lane commit: the starter
referenced a missing pickup asset, the pause scenario never paused, the seeded scenario
used `seed: null` and did not compare a generated value, and scheduler clearing preceded
scene exit. All four were repaired, then typecheck, lint, test, budget, scaffold, and
generated-starter checks were rerun. No second reviewer was run after this repair, per the
Linchpin review contract.
