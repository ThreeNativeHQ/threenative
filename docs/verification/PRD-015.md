# PRD-015 verification

Date: 2026-08-04

Status: implementation complete; the generated starter consumer passes its complete
playtest suite. Browser proof ran under Chromium's WebGL2 fallback because this environment
has no WebGPU adapter.

## What shipped

- The starter scene calls the generated spring arm, rounded shapes, lighting, postprocess,
  gradient sky, pickup audio, and kill-plane respawn path.
- Starter and minimal players use `CharacterBody3D.moveAndSlide(dt)` with `body.velocity`,
  coyote time, and a jump buffer; `#verticalVelocity` is absent.
- Starter `Boot` awaits a texture before entering `Play`, and `Menu` exposes pause state
  with `aria-pressed`.
- The template contract test checks every render module and runtime export has a caller,
  rejects starter `BoxGeometry` use, and rejects the superseded vertical-velocity path.
- The playtest runner now evaluates screenshot frame diffs and viewport-region metrics,
  and exposes a runtime world-seed assertion.
- The starter package test script runs play, coyote, buffer, look, pause, respawn, and seed
  scenarios against a managed Vite server.

## Fail-closed controls

The source-level negative controls below were observed during implementation and restored:

| Control | Observed red result |
| --- | --- |
| Detach the spring-arm call | Template contract found `createSpringArm(ctx.camera` absent |
| Skip the `setupSky` call | Template contract found `setupSky(ctx.scene` absent |
| Add an unused render export | Render-export test reported no live caller |
| Replace a starter rounded mesh with `BoxGeometry` | Starter geometry contract rejected it |
| Set coyote time or jump buffer to `0` | Movement contract rejected the required constants |
| Remove the kill-plane respawn call | Scene contract rejected missing `player.respawn()` |
| Mute pickup audio | Scene contract rejected missing `this.#audio?.play(buffer)` |
| Drop the `Boot` texture `await` | Load-order contract found no awaited texture load |
| Make the pause button a no-op | Menu contract found no `game.pause()` call |
| Reintroduce `#verticalVelocity` | Zero-match legacy-path gate failed |

The first coyote scenario draft also failed at runtime: one long held-key step ended in a
grounded jump with `coyoteJumps=0`. Five explicit 40-tick keydown/keyup steps now reach the
edge reliably and the exact `coyoteJumps=1` assertion passes. This is the runtime proof that
the scenario is not merely asserting a self-authored counter beside a jump.
