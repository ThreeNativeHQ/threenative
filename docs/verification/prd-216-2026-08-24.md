# PRD-216 verification — React UI on native

**Date:** 2026-08-24
**Result:** PASS on browser, Linux desktop native, and a physical Pixel 8. iOS is unproven.

## What shipped

This is an engine fix. Games cannot portably create a React renderer over a native framebuffer;
`@threenative/core/react` owns that mechanism. The starter keeps all appearance in generated
`src/ui/` source. The main `@threenative/core` entry remains React-free; React and
`react-reconciler` are optional peers reached only through the `./react` subpath.

The public path is `createReactOverlay({ canvasLayer })`, with React Native-shaped `View` and
`Text` primitives. It maps React commits to Three.js objects, lays them out in framebuffer pixels,
and draws them through the existing `CanvasLayer`. Unknown elements, styles, and glyphs fail by
name. A thrown component leaves the last good overlay mounted and can recover on the next render.

## Red-green evidence

| Contract | Red observed | Green proof |
| --- | --- | --- |
| React 19 host | The standalone probe first threw `ReferenceError: setTimeout is not defined`; missing React 19 host hooks also threw at mount. | `docs/verification/prd-216-spike/` mounts, updates 200 times, idles 10,000 flushes, and unmounts under vendored QuickJS 0.11.0. |
| Native orientation | The Android integration test reported `SDL window creation overwrote the declared landscape orientation.` | `packages/runtime-native/__tests__/android-orientation-integration.spec.ts`: 4/4 passed; the live Pixel capture is 2400x1080. |
| Native-only web renderer | Planting `react-dom/client` in the portable entry failed the Android build with `TN_NATIVE_WEB_ONLY_UI`; exit 1. | The planted import was removed; the real Android bundle built and launched while the guard stayed unchanged. |
| LOC kill switch | Before consolidation, the starter's native adapter plus mount was 86 physical lines versus the 69-line geometry HUD. | The mount now lives with the adapter. `count-loc.spec.ts` is 8/8 green and `count-loc.ts` reports `native React HUD LOC: 61 (geometry HUD 69)`. |
| Capability/docs gate | The first full suite failed on unsupported `./react` scanning and missing manifest tags. | The scanner covers `./react`; 50 public functions/classes have complete tags, and budgets pass. |

The host/layout unit suite covers mount, update-in-place, removal, z-order, resize, idle commits,
unsupported style/glyph failures, component error recovery, and disposal. Removing the relevant
host mutation, resize listener, error boundary callback, or style/glyph check makes its named test
red rather than failing elsewhere.

## External steering

`crouter --dangerously-skip-permissions --print` was used during implementation. Its actionable
reviews identified the stale sandbox tarball, the 4000-pixel centering wrapper, the need for a
component genuinely shared between web/native, production `NODE_ENV` ownership in the native
bundler, an obsolete Vite plugin, and unsupported native diagnostics. Those findings drove the
corresponding fixes. Two final broad/narrow reviews and the final acceptance invocation produced no
response before their 3-4 minute timeouts, so no final external `PASS` is claimed.
