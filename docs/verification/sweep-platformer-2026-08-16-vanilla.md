## Friction ledger

| API or surface | What blocked the build | Workaround | Evidence |
| --- | --- | --- | --- |
| bridge `diagnostics` channel | Publishing the debug HUD through the documented channel — `{id:"fps",label:"FPS",value:30}` and two more — was counted as three runtime errors, failing both sealed scenarios. The generated AGENTS.md says the channel "returns current runtime diagnostics" and the option is typed `() => JsonValue[]` with no doc comment, so a game that used the documented API as documented could not pass. | None available at build time; the arm did not know it had happened. | Confirmed in `packages/playtest/src/runner/runner.ts`, which spread the channel into `recentRuntimeErrors` unfiltered while filtering the console half. Fixed this round with `packages/playtest/__tests__/runtime-readouts.spec.ts`. |
| screenshot and inspection harness | 151 hand-written lines before anything could be looked at: headed Chromium, the four WebGPU flags, adapter readback by field name, a scripted-input mini-language, a state dump and a PNG write. Named by the builder as its single largest non-game cost. | `tools/shot.mjs`, `tools/tick-drive.mjs` and `tools/bridge-check.mjs`, preserved at `docs/benchmark/rounds/round-9/salvage-vanilla/tools/`. | The other arm wrote 70 lines of the same thing. Both are off-instrument: neither counts toward either arm's LOC. |
| kinematic character controller | About 155 hand-written lines, and the one genuinely hard defect of the build: the first version collided only with platform tops, so a jump landing short passed through a raised ledge into the void behind it. Three consecutive playthroughs failed — 10 respawns, lives 0, goal never reached — before it was found. | About 35 lines of least-penetration push-out. | This is what a `CharacterBody3D` with `moveAndSlide` exists to prevent, and it is the clearest thing the framework arm did not have to write. |
| jump input semantics | Two separate traps. A `keyboard.press` shorter than a frame is dropped by a naive held-key map. And a held key re-armed the jump buffer every tick, producing a jump per landing, which would have inflated `state.jumps` under any proof that holds the key. | Rising-edge detection; 60 ticks of held Space now yields exactly `jumps:1`. | Verified by driving the real bridge from Playwright. |
| scene primitives | 628 hand-written lines for islands, pines, bushes, flowers, fence posts, a catenary rope, a plank bridge, crates, boulders, clouds, coins, a mushroom walker, a goal flag, a waterfall, a castle and a windmill. Mostly routine; the rope needed real quaternion orientation along a sag curve, and the star coin needed `Shape` plus `ShapeGeometry` because `CircleGeometry(r, 5)` is a pentagon. | Written by hand. | This is the arm that won the visual column, so the cost bought something. |
| gradient sky | About 18 lines: sphere, `BackSide`, per-vertex colours through a smoothstep, and `fog: false`. There is no built-in gradient sky, so every project rewrites it. | Written by hand. | The arm arrived at `fog: false` independently — the same property the framework template was missing, and the reason its distance kept its colour. |
