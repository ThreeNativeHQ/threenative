## Checksum-locked no-Xcode iOS handoff — implementation complete, execution open

The runtime package now ships `package-ios.mjs`. On an arm64 Mac it obtains the
`ios-simulator-arm64` archive through the same release checksum lock as desktop/Android (or
requires an explicit local SHA-256), unpacks the unsigned simulator `.app`, replaces only
`native-smoke.js`, and writes a bundle/host provenance report. Non-Darwin, non-arm64, corrupt
archive, device/signing, and missing-lock cases fail closed.
