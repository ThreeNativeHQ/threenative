  to `<project>/agent-docs/` with the same placeholder substitution and path safety as source

  `sculpt-loop`, `look-at-it-and-budget-the-look`, `ctx-surface`. New shared fragment
  `playtest-fail-closed` replaces two paragraphs that were duplicated verbatim in all seven.

  `finding-assets.md`, `sculpt-from-a-reference.md`, `capture-the-frame.md`, `ctx-cookbook.md`,
  `gameplay-recipes.md`, `visual-baseline.md`. Copied into every generated project as
  `<project>/agent-docs/<page>.md`.
- All seven template `AGENTS.md` reduced; duplicated paragraphs deleted (starter's repeated
  navigation paragraph; the `moveAndSlide` aliasing essay that appeared verbatim in starter,
  minimal, platformer, shooter, racing, action-rpg; the layout mermaid diagrams in starter and
  minimal). `CLAUDE.md` mirrors regenerated by `pnpm sync:agents`, never hand-edited.
- `packages/create-threenative/__tests__/scaffold.spec.ts` — new `should copy bounded references
  with project placeholders`; `STARTER_PATHS` now includes the six bundle paths.
- `scripts/sync-agent-docs.ts` — `--check` failure message now carries the
  `RED observed: agent docs out of sync` prefix its negative control asserts.

**Reference-link convention.** Templates name pages by their generated-project path,
backticked (`agent-docs/finding-assets.md`) or as a Markdown link. Markdown links written for the
generated project would resolve against repo locations in-repo and fail `pnpm check:docs`
(`git ls-files` walks every tracked `.md`); backticked literal paths are the convention this repo's
own instructions already use, work identically for a cold agent, and are what both validators
(the checker and `assertReferenceBundle`) scan for.
