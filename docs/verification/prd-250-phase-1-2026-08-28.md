## Perf observation (no claim)

A/B of the packed 300-frame desktop gate, main vs Phase 1, same worktree and build directory:
`render.p50 1.3 ms`, `frame.p50 1.63 ms`, 0 hitches on both arms. The change adds one
queue-empty check per frame (`WorkerRegistry::processWorkerMessages`) and one extra state field.
Frame continuity while the worker computes is the correctness gate; no speedup is claimed and
`TN_NATIVE_WORKER_PROOF_PASS` framesAdvanced is an observation, not a performance result.

## Named consequences, not yet owed

- Emscripten-style worker consumers (KTX2/Draco transcoder workers rely on `importScripts`,
  `self.location.href` and the `(var X = …)` eval patch the old main-thread polyfill provided)
  now fail in the worker isolate. The failure is loud, not silent: the isolate reports top-level
  eval failure as a `Worker` `error` event, and Phase 1's contract requires no main-thread
  fallback. Desktop-native compressed-texture games are affected until Phase 2/3 admit the
  worker-side scope rows.
- Mobile rows stay `UNVERIFIED` per the PRD: Android, iOS simulator and physical devices have
  not executed the packed proof.
