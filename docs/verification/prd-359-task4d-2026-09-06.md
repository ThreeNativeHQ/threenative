## Scope

The reference Go server now issues random one-time credentials only from its
loopback admin listener, stores SHA-256 hashes bound to room/player/expiry, and
consumes a credential atomically during the `/game` HELLO validation. `Origin`
allowlisting remains a browser admission check and is not used as native identity.
The public `/game` handler injects the validator; a validator-free configuration
remains fail-closed.
