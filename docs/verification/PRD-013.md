# PRD-013 verification

Date: 2026-08-04

Status: implementation complete; final repository and generated-consumer gates are
recorded below.

## What shipped

- `--template platformer` now scaffolds the editable character, patrol, pickup,
  checkpoint, terrain, sky, palette, rig, HUD, and ten playtest scenarios.
- `CharacterBody3D.oneWayGroups` filters one-way colliders only while rising and
  clears the filter on subsequent ticks.
- The playtest tag evaluator treats an absent tag as count `0` only when the runtime
  tag channel is present; an unavailable channel still fails closed.
- `coyoteJumps` makes the coyote-time proof distinguish a real coyote jump from the
  existing double-jump fallback.

## Checkpoint controls

`packages/create-threenative/__tests__/platformer.spec.ts` covers the two
template-local fail-closed controls named by the PRD: an empty checkpoint list throws,
and repeated hits during the `PLATFORMER_FEEL.invulnerabilityTime` window decrement
hearts only once. `Patrol` and `Checkpoints` receive their feel values from the
`Character.ts` source of truth without importing framework or rendering dependencies
into the package test.

The read-only Linchpin review requested two changes: enforce the platformer LOC limit in
`scripts/count-loc.ts`, and move patrol/checkpoint feel values into `Character.ts`. Both

focused red controls now cover every declared PRD-013 gate.
