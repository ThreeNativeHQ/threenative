# PRD-359 task 4a evidence

The Go adapter is in `packages/runtime-native/examples/webtransport/server/protocol.go`.
The `/game` caller is `main.go:251-278`; it registers the exact reference channel map
but leaves the validator nil until task 4d, so an unauthenticated session is rejected
before HELLO parsing or game-state allocation. `/echo` remains the transport-only path.

## Green

The decoder now bounds only the incomplete frame, allowing complete frames to be
coalesced in one reliable-stream read (`protocol.go:259-284`). The control reader also
reads the declared payload before decoding the complete frame (`protocol.go:897-921`).

```text
$ go test -count=1 ./...
ok  threenative.local/networking-reference  0.003s
$ go test -race -count=1 ./...
ok  threenative.local/networking-reference  1.011s
$ go vet ./...
(no output; exit 0)
$ go build -o /tmp/tn-network-server .
(no output; exit 0)
```

The required tests are collected in `protocol_test.go:66,193,241,275,290,314`:
`TestVectors`, `TestSplitFrames`, `TestMalformedFrame`, `TestDuplicateBind`,
`TestChannelMismatch`, and `TestNegotiatedLimits`. The literal-vector mutation proof
flipped the `data-ab` payload byte:

```text
$ go test -run '^TestVectors$'
--- FAIL: TestVectors
    protocol_test.go:...: data-ab-channel-1: payload bytes differ
FAIL
exit status 1
```

Restoring the literal returned the suite to green.

The live `/game` HELLO/BIND proof is intentionally not claimed in this row: task 4d
must inject the one-time credential validator before the endpoint may accept a session.
