## Phases 1–2 — the corpus and the offline replay

The corpus already existed; this run added the missing end-to-end gate and one missing provenance

**The corpus** (~21 KB total, every byte licence-named):

- `packages/ueformat/fixtures/*.uemodel` — three synthetic fixtures, ~1.3 KB; provenance added in

**The offline replay** (`packages/assets/__tests__/unreal-replay.spec.ts`, `0acee6b2`):

```
decodes the pinned UE5.7 package, converts it, compiles it, and matches the golden structure  ✓
fails for the right reason when the UE5 header path is broken                                  ✓
```

The chain: `parseUAssetStaticMesh` (Oodle codec supplied) → `createThreeGeometry` → non-interleaved
GLB via gltf-transform → `compileAssets` → structural fingerprint compare. The golden pins meshes,
primitives, component type, accessor bounds, triangle and vertex counts — a gltf-transform patch
bump must not fail it, a dropped primitive must. No network, no credentials, no external
executable in the offline half.

**Observed reds:**

- `flipping the package tag byte fails the decode with UAssetError, not invented geometry` — PASS;
  goes red if the decoder ever returns invented geometry for a corrupt header
- `structural, not byte` — holds by construction; the fingerprint has no byte- or version-level
  fields. Negative control for the opposite direction (a dropped material/primitive) is the
  fingerprint's `primitives` and `triangleCount` fields; breaking the decode path was demonstrated
  live above.
