# PRD-359 owned quiche dependency CI

Status: integrated and locally checked; actual CI producer execution and the
complete nine-target release remain pending. No release was published.

The workflow invokes the existing producer once with fresh pinned quiche source,
recursive submodules and an external Cargo target directory. It installs Rust
1.96.0, Go 1.26.3, CMake 4.4.2, Python 3.12 and PyYAML 6.0.3. All three Python
suites run before the build. Both change filters include the validator and tests.

Publication requires the exact `quiche-owned-v1` tag and all nine target archives
and manifests. The validator checks schema, identity against producer constants,
target mapping, ZIP layout, outer and member SHA-256 digests, and emits exactly
18 asset paths. The shell passes that explicit array to `gh release create`.
The Linux-only matrix cannot publish a partial release. Remaining platform
recipes and execution stay in the separate open ledger row.
