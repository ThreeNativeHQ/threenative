## Change

Test-owned temporary directories now use `makeTempDir` or `makeTempDirSync`, which register
Vitest cleanup with `onTestFinished`. `makeTempDirSyncAt` preserves callers that need a specific
parent. A process-exit fallback covers non-Vitest test/config callers. The guard rejects
unregistered `mkdtemp` and `mkdtempSync` calls across TypeScript/TSX and runtime-native MJS test
files, and records the reviewed production allowlist with reasons. The root test command now
keeps the temporary-directory count open across the entire build, package-test, and root-test
sequence.
