# PRD-052 verification — mobile-safe platformer navigation

**Result:** candidate B passed on browser, Linux desktop, and Android x86_64 emulator,
2026-08-09. Navmesh navigation is browser-only; iOS and physical hardware are not claimed.

## Phase 0

The unchanged Recast platformer produced a 7,645.11 kB desktop bundle, then failed before
frame 1:

```text
[V8] .threenative/game.js:112785: SyntaxError: Cannot use 'import.meta' outside a module
var _scriptName = import.meta.url, readBinary;
[Modules] Failed to compile module: .threenative/game.js
[Screenshot] No rendered frame available yet
```

The consumer census found zero source consumers in 87 sweep directories / 3,034 `src`
files and 17 example TypeScript/JavaScript source files. The only archive hits were four
copied declarations under `framework-types` in the 2026-08-09 exploration and open-world
archives. The 161-name `round:deletions` result contains no navigation symbol because the two
ledgers it intersects contain no navigation declaration; it is not evidence of use or non-use
for this API.

## Replacement

Runtime implementation changes are confined to generated game source. The platformer's fixed
blocker now has a two-corner route at z ±3.05, with one chaser on each side and short-range
peer separation. Recast plugin, region, agent and obstacle imports were deleted. The existing
character controller still owns movement.

```text
Chaser.ts:                         79 lines total, 31 steering lines
platformer template:              1,159 LOC (was 1,200)
navigation symbols in template src: 0
```

## Native execution

Linux desktop built a 6,322.78 kB import-free bundle and rendered 300 frames in 9,471 ms.
[Desktop screenshot](PRD-052-desktop.png), SHA-256
`f0021069efc3975f8b5c2f9c1db903eb806002c42cb981df519b251c9679eca7`.

Android used QuickJS on emulator `emulator-5554` (`x86_64`, 1080×2400). The APK built and
emitted `TN_NATIVE_SMOKE_READY`, `TN_NATIVE_SMOKE_FIRST_FRAME`, and
`TN_NATIVE_SMOKE_300_FRAMES:300` with no start failure. [Android screenshot](PRD-052-android.png),
SHA-256 `87806a43fff61eab4f3cf85fb692a3894d3000f4cd2a472091ad79b68b701b65`.

A fresh minimal scaffold independently assembled and installed on the same emulator. Its
4,002.42 kB bundle also emitted READY, FIRST_FRAME, and 300_FRAMES. Together with the starter
execution in `docs/verification/PRD-050.md`, this executes all three scaffoldable templates
on Android rather than inferring support from a shared build path.

## Boundaries

- `@threenative/physics/navigation` remains available to browser projects; it was not
  deleted or given a second backend.
- Desktop Recast is not claimed: its executed artifact failed at `import.meta`.
- The iOS-target platformer bundle compiled and passed the native compatibility check. Final
  simulator packaging correctly stopped on Linux with `iOS simulator packaging requires a
  darwin-arm64 host`; iOS packaging and execution are therefore not claimed.
- Android arm64 and physical hardware are open.
