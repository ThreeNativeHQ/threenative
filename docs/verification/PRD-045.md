logs, liveness and screenshots. Missing apps, launch PIDs, bridges, or commands fail closed.


The iOS suite proves an observed pass, a wrong value exiting 1, a missing bridge exiting 2,
a misspelled assertion rejected before launch, and an unsupported network assertion exiting

No `xcrun`, Xcode installation, Apple runner, or physical iOS device exists on this Linux
host. The unchanged scenario and three controls have therefore **not** run on a simulator;

JavaScript/transport semantics, not physical GPU-driver behavior. Criterion 8's CLI and
honest device/CI documentation are implemented. Default CI excludes device scenarios; the
native platform workflow is opt-in and unexecuted.
