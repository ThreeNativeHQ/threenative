## Criterion 7 correction — 2026-08-10

**A simulator did run, and it was not an iOS simulator.** The hosted `macos-15` lane has been
executing since 2026-08-09, and `devicePlaytest` in `simulator-report.json` shows every
required control producing its exact exit code on the unchanged `device-smoke.playtest.json`:

```text
device-smoke.playtest.json                 exit 0  "pass": true
device-smoke-wrong-value.playtest.json     exit 1  TN_PLAYTEST_VISIBILITY_FAILED
device-smoke.playtest.json, bridge absent  exit 2  TN_PLAYTEST_BRIDGE_MISSING
device-smoke-misspelled.playtest.json      exit 2  TN_PLAYTEST_SCENARIO_INVALID
device-smoke-network.playtest.json         exit 2  TN_PLAYTEST_UNSUPPORTED_ON_TARGET
```

The same reports also record `"simulator": { "name": "Apple Vision Pro", ... }`, a 2732×2048
screenshot, and **no `runtime` field**. Runs `31313092745` (`e38439c`) and `31434881982`
(`00cfad2`) both selected a **visionOS** device.

![The captured "iOS" screenshot: the visionOS simulator's living-room environment with the

*Exhibit: `simulator-core.png` from run `31434881982`, downscaled from 2732×2048. The room is

Cause: `chooseSimulator()` flattened `xcrun simctl list devices available --json`, whose map is
keyed by runtime identifier while the device objects carry no runtime of their own. Flattening
discarded the only OS evidence and `devices[0]` was an arbitrary pick across visionOS, watchOS,
tvOS and iOS.

**Criterion 7 is therefore still unmet, for a new reason.** It reads "the same scenario file
passes on the **iOS simulator**"; visionOS is not iOS, and this PRD's own instruction not to
soften the requirement to fit the hardware applies. PRD-045 stays in `native/blocked/`.

PRD-065 Phase 0 pins selection to `SimRuntime.iOS-*`, prefers an `iPhone`, throws
`TN_IOS_SIMULATOR_ABSENT` rather than substituting a non-iOS device, and records the runtime in
the report. Locally: 8 tests pass in `packages/runtime-native/tests/ios-contract.test.mjs`,
`pnpm lint` and `pnpm typecheck` green; the pre-fix selector was restored in place and observed
red. **No macOS run has executed since the fix**, so criterion 7 remains UNVERIFIED rather than
MET — re-evaluate against the first post-fix report that names an iOS runtime.
