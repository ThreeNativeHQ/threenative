# ThreeNative

ThreeNative is a small, vanilla-Three.js-first game framework for WebGPU games. The
framework owns bootstrap, lifecycle, input, physics bindings, UI state, and playtest
hooks. Generated `src/render/` code owns the look.

## Local commands

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm test:browser
```

The runnable examples are `examples/abyss-vanilla/` (frozen control) and
`examples/abyss-framework/` (framework Abyss port and physics proof scene).
